# Premium Restaurant Ordering Website

A modern, responsive restaurant ordering website designed for restaurants, cafés, and food businesses.

## Features

* 🍔 Large digital food menu
* 📦 Deals & Boxes
* 🍦 Separate Ice Cream category
* 🥤 Separate Drinks category
* 🛒 Shopping cart
* 💳 Checkout and payment options
* 🚚 Home Delivery and Pickup
* 📱 Mobile-friendly responsive design
* 👨‍💼 Owner Portal for restaurant management
* 📋 Product and category management
* 📦 Deal and Box management
* 🧾 Order management
* 📞 Phone and WhatsApp ordering
* 🎨 Restaurant branding and customization
* ⚡ Fast and lightweight interface

## Owner Portal

The Owner Portal allows restaurant owners to manage their restaurant information, menu, products, deals, boxes, orders, delivery settings, payment options, branding, and other website settings.

## Project

This repository contains the source code for the restaurant ordering website.

Built as a customizable restaurant website that can be adapted for different restaurants and food businesses.
